House price prediction:

This project aims to predict house prices based on different parameters such as its location, no. of rooms, area , society etc. I used my python python skills and implemented it with scikit-learn framework to build this model. This type of data usually requires only linear regression for prediction but since it is my first project I used multiple regression techniques to try and analyze different results. Dataset is sourced from Kaggle.com and I took a lot of help from kaggle community and chatgpt.
